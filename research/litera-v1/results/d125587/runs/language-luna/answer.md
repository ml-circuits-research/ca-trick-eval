# Raport de verificare — factura L-48

**Dosar:** AT-2041  
**Beneficiar:** Litera Instrumente SRL (RI-62)  
**Valoare facturată:** 48.000 EUR  
**Data analizei:** 12.11.2026, ora 14:00 UTC

## Decizie

**Suma autorizabilă: 0 EUR.** Documentele nu justifică plata facturii L-48 în condițiile mandatului.

## Motivare și probe

Mandatul permite plata integrală numai dacă există o aprobare financiară activă pentru **identificatorul exact al dosarului**, același beneficiar și aceeași valoare. Dacă nu sunt îndeplinite toate condițiile, suma autorizabilă este 0 EUR, fără plată parțială. [01_mandat.md, M2]

Aprobarea AF-18 este activă la ora analizei, autentică și nerevocată; indică beneficiarul RI-62 și valoarea de 48.000 EUR, identice cu cele din mandat. [02_aprobare.md, R2–R3] Însă referința din aprobare este `АT-2041`, cu litera inițială **А chirilică**, în timp ce mandatul identifică dosarul ca `AT-2041`, cu **A latină**. Șirurile nu sunt identice, iar mandatul cere potrivirea exactă. [01_mandat.md, M1–M2; 02_aprobare.md, R1]

Fișa de transmitere confirmă că pachetul include mandatul, factura și AF-18; precizează și că fișa nu constituie o aprobare suplimentară. [03_transmitere.md, N1–N2] Mandatul afirmă că pachetul conține toate aprobările financiare existente la ora analizei. [01_mandat.md, M3]

Prin urmare, deși beneficiarul, valoarea și activitatea aprobării corespund, aprobarea nu este pentru identificatorul **exact** cerut. Condiția cumulativă de autorizare nu este îndeplinită, iar regulile dosarului impun respingerea plății integrale și exclud autorizarea parțială.
