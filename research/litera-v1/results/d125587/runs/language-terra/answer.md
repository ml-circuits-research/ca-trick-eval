# Raport pentru beneficiar — factura L-48

**Decizie: plata facturii L-48 nu este justificată în condițiile dosarului. Suma autorizabilă este 0 EUR.**

Factura are valoarea de **48.000 EUR**, iar beneficiarul plății este Litera Instrumente SRL, identificator RI-62. Mandatul permite plata integrală numai dacă există o aprobare financiară activă pentru **identificatorul exact al dosarului**, același beneficiar și aceeași valoare. Dacă această condiție nu este îndeplinită, nu se autorizează nici plata parțială. [Mandat, M1–M2]( /case/01_mandat.md)

Aprobarea AF-18 este autentică, activă și nerevocată; beneficiarul și valoarea din ea corespund facturii. Referința dosarului nu corespunde însă exact:

| Document | Referință | Primul caracter |
|---|---|---|
| Mandat | `AT-2041` | `A` latin, U+0041 |
| Aprobarea AF-18 | `АT-2041` | `А` chirilic, U+0410 |

Caracterele seamănă vizual, dar sunt distincte. Mandatul precizează că aprobarea este valabilă exclusiv pentru referința consemnată în ea; prin urmare, AF-18 nu satisface cerința pentru dosarul `AT-2041`. [Mandat, M2]( /case/01_mandat.md); [aprobarea AF-18, R1–R3]( /case/02_aprobare.md)

Mandatul arată că pachetul conține toate aprobările financiare existente la ora analizei și că celelalte condiții — comerciale, recepția și disponibilul de numerar — sunt îndeplinite. Fișa de transmitere nu constituie o aprobare financiară suplimentară. [Mandat, M3]( /case/01_mandat.md); [fișa de transmitere, N2]( /case/03_transmitere.md)

Pentru autorizarea celor 48.000 EUR este necesară o aprobare financiară activă care să indice exact dosarul `AT-2041`, același beneficiar și aceeași valoare.
