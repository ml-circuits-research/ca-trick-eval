# Raport pentru beneficiar — tranșa VL-18

**Suma autorizabilă la 12.11.2026, ora 14:00 UTC este de 72.000 EUR. Documentele susțin plata integrală a tranșei.**

Contractul prevede o tranșă indivizibilă de 72.000 EUR, plătibilă dacă există două rapoarte conforme pentru VL-18, emise de laboratoare diferite, pe probe provenite din două evenimente distincte de prelevare. Celelalte condiții sunt declarate îndeplinite. [Contract, P1](/case/01_contract.md)

Cele două rapoarte sunt conforme, semnate și valabile la momentul evaluării: Atlas a emis RA-44 pentru proba LA-21, iar Boreal a emis RB-93 pentru proba LB-08. Laboratoarele sunt persoane juridice diferite, fără acționariat comun, iar conformitatea măsurătorilor este certă. [Rapoarte, L1–L3](/case/03_rapoarte.md)

Problema materială este dacă probele provin din **prelevări distincte**. Registrul autorizat stabilește următoarele trasee:

- **LA-21:** PV-31 → C-11 → A-61 → LA-21.
- **LB-08:** PV-32 → C-12 → A-62 → BX-09 → LB-08.

Registrul identifică PV-31 și PV-32 ca prelevări separate din VL-18, ambele anterioare analizelor. Recodificarea A-62 în BX-09 a avut loc la transport; ea nu constituie o prelevare nouă. Distincția decisivă este însă între PV-31 și PV-32, astfel că cerința contractuală este îndeplinită. [Registru, T1–T3](/case/02_trasabilitate.md); [Contract, P2](/case/01_contract.md)

Fișele de predare sunt rezumate administrative și nu certifică evenimentele de prelevare. Contractul acordă prioritate registrului de trasabilitate, care este declarat complet și autorizat; prin urmare, concluzia se sprijină pe registru și pe rapoartele de laborator. [Contract, P2–P3](/case/01_contract.md); [Fișe de predare, H0–H1](/case/04_predare.md)
