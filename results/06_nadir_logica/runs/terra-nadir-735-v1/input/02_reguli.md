# Invariantele registrului Nadir

[I1] Enunțurile de mai jos sunt simultan adevărate pentru starea actuală. Fiecare „dacă ... atunci ...” are sensul logic obișnuit: premisa adevărată impune concluzia; premisa falsă nu impune singură starea concluziei.

[R1] Dacă J este activ, atunci E este activ.

[R2] Dacă S este activ, atunci B este inactiv.

[R3] Dacă V este activ, atunci D este inactiv.

[R4] Dacă J este inactiv, atunci C este activ.

[R5] Dacă B este activ, atunci V este activ.

[R6] Dacă V este activ, atunci C este activ.

[R7] Dacă E este activ, atunci C este inactiv.

[R8] Dacă V este activ, atunci B este activ.

[R9] Dacă D este activ, atunci S este activ.

[R10] Dacă J este inactiv, atunci D este activ.
