# Invariantele registrului Nadir

[I1] Relațiile de integritate ale registrului la data de referință:

[R1] Dacă J este activ, atunci E este activ.

[R2] S este activ numai dacă B este inactiv.

[R3] Pentru ca indicatorul V să fie activ, este necesar ca indicatorul D să fie inactiv.

[R4] Este exclusă combinația: J este inactiv și C este inactiv.

[R5] În orice stare validă, B este inactiv sau V este activ; cel puțin una dintre cele două afirmații este adevărată.

[R6] Dacă V este activ, atunci C este activ.

[R7] E este activ numai dacă C este inactiv.

[R8] Pentru ca indicatorul V să fie activ, este necesar ca indicatorul B să fie activ.

[R9] Este exclusă combinația: D este activ și S este inactiv.

[R10] În orice stare validă, J este activ sau D este activ; cel puțin una dintre cele două afirmații este adevărată.
